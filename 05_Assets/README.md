# Brand Assets

Logo and brand template files.

---

## Logo

| File | Use |
|------|-----|
| `STARADIO_Logo_Red_PNG.png` | Primary logo. Red strokes, white interior, transparent background. For light backgrounds. |
| `STARADIO_Logo_White_PNG.png` | All-white silhouette, transparent background. For dark or photographic backgrounds. |
| `STARADIO_Badge_PrintMaster_S700.pdf` | **Vector print master.** The production artwork — use this for badges, decals and physical nameplates, never the PNGs. |

### Specifications

| Property | Value |
|----------|-------|
| Aspect ratio | 7.89 : 1 |
| Badge trim size | 180 × 22.7 mm |
| PNG resolution | 5102 × 647 px |
| Background | Transparent |

### Clear space and minimum size

Keep clear space around the logo equal to the height of the letter **S**. For print
work the badge should not be reproduced below **40 mm wide** — below that the
counters inside the letters fill in.

### Do not

- Recolour the red to a different hue
- Stretch, condense or re-space the letters
- Add a drop shadow, bevel or gradient
- Place the red logo on a mid-tone or dark background — use the white version
- Reconstruct the logo from the PNG for large-format printing; use the PDF master
