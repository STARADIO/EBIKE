Logo and brand template files.

## Status

Master logo artwork is being prepared for publication here. This folder is
currently empty of binaries.

If you need brand assets for a reseller listing, a marketplace profile or a press
enquiry, contact us through the [website](https://staradiobikes.com).

---

## Conventions for anything added here

| Type | Naming |
|------|---------|
| Logo raster | `STARADIO_Logo_<colour>_<format>.ext` — e.g. `STARADIO_Logo_White_PNG.png` |
| Logo vector | `STARADIO_Logo_<colour>_<format>.svg` |
| Template | `STARADIO_<type>_Template_V<version>.ext` |

Colours: use the word, not a hex value, in the filename. Add a one-line note above
each file stating what it is and when it was last revised.
